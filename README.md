## 🛠️ ツール

### 🎨 Stable Diffusion / PixAI / NovelAI Prompt Picker
- https://yuka1201.github.io/yuka1201/stable-diffusion-prompt-picker.html
- タグをタップして選ぶだけで、画像生成プロンプトを組み立てられるツール
- タグ893種、カラーピッカー、重み調整、共有URL（開くと構成を復元）対応
- 表示テーマは白／黒／優花の3種類

### 💬 漫画作成サイト
- https://yuka1201.github.io/yuka1201/manga-maker.html
- 画像やAI生成画像にコマ割り・フキダシ・効果をつけて漫画ページが作れるツール
- コマ割り12種＋カスタム格子、枠線の太さ・コマ間隔・ページ番号表示の調整、フキダシ12形状、集中線・効果音、複数ページ、PNG保存対応

### 🎨 Misskeyテーマメーカー
- https://yuka1201.github.io/yuka1201/misskey-theme-maker.html
- Misskeyのテーマを、サンプルのプレビューを見ながら直感的に作れるツール
- テンプレート6種、プレビューをタップして色を編集、そのまま使えるテーマコードを出力
